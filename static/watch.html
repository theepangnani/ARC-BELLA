Counts and costs only. No prompts, replies or transcripts are stored — a usage log that quietly became a conversation log would be a far more sensitive file than this one, sitting in the same folder with the same protection.

Costs are worked out from the token counts the API reports, at the rates in your .env. Cached input is billed at a tenth and counted separately, so the figure here is what you actually spent rather than what it would have cost without caching.
