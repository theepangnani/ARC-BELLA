# Pinned exactly, on purpose.
#
# Every line here used to be `>=`, which meant a fresh install today and a
# fresh install next month were not the same program. That is a strange thing
# to allow in something that repairs itself when it breaks: selfheal.py can
# restore a half-written notes.json, and it cannot do anything at all about
# edge-tts changing its API underneath ARC between one `pip install` and the
# next. The drift had already happened — edge-tts asked for >=6.1 and this
# machine is running 7.2.8, a major version it was never tested against.
#
# The trade is that security updates no longer arrive on their own. That is the
# right way round here: this runs on one machine, and an upgrade that breaks
# the voice at 7am is worse than an upgrade that waits until someone chooses
# it. To move: bump the line, run tests/run_all.py, commit the two together.
